    How MergeMaster works

    MergeMaster fills placeholders in your message text so you can send consistent, personalized messages. Everything runs in your browser—there is no server. Use the tabs above to switch between editing templates, composing one message at a time, or building a list of many messages.

    Templates

    A template is a saved preset: a name, the message body (the field labeled “Template”), and two bracket pairs—regular and global—that wrap variable names in the text.

    • Regular variables default to {{ … }} (for example {{name}}). They are filled per message or per row.
    • Global variables default to [[ … ]] (for example [[campaign]]). On List compose, one value applies to every row.
    • Case-insensitive names — {{name}}, {{Name}}, and {{NAME}} are the same variable. The editor and compose screens list each name once, with a capital first letter (e.g. Name). Your template text can keep any casing you like.

    New template creates a preset; Save stores your edits in this browser. Export JSON / Import JSON moves templates between devices or backs them up. Hover the small section titles in the editor for more detail on brackets and detected names.

    Compose

    Pick which saved template to use, then fill the Variables fields that appear. The Result updates as you type. Use Copy to clipboard when you are done.

    You can load a source file instead of typing: a comma-separated file whose first row lists variable names (matching your regular placeholders, without the brackets). Header matching is case-insensitive (a column NAME fills variable Name). One data row fills the form; several data rows produce several merged blocks in the result, separated by a line of ---.

    List compose

    Built for many recipients at once. Choose a template, set any Globals once (labels use a capital first letter; names are case-insensitive), then import a source file with a header row plus one row per person. Column headers match variable names case-insensitively. You get one card per row, each with its own Copy button.

    Add row adds a manual row if you do not want to use a file. Clear list & file removes imported rows and clears the file input. Changing the template also clears the list so previews always match the selected preset.

    Source files

    “Source” means a small spreadsheet-style file (commonly exported as .csv): the first row is column headers; those names should match your regular variable names. Matching is case-insensitive (header email, Email, and EMAIL all map to the same variable). Globals are not read from the file—set them in the Globals section on List compose.

    Variable names

    Everywhere in MergeMaster, a variable name is treated the same no matter how you capitalize it in the template or in a source file. name, Name, and NAME are one variable.

    • In the template text, you can write placeholders in any casing; duplicates that differ only by case count as a single variable.
    • On Compose and List compose, field labels are shown with a capital first letter (e.g. Name) for readability.
    • In source files, column headers are matched case-insensitively to those variable names.

    Your data

    Templates are stored in localStorage on this device only. Clearing site data in your browser will remove them unless you have exported JSON. If you opened an older version of MergeMaster here, your data may have been moved automatically to the current storage key.
